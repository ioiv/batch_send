# ChainKit 链上工具箱

ChainKit 是一个基于 React、TypeScript 和 Vite 的工具站。目前包含 SOL / EVM 批量发送、CreateX 部署、ERC20、EVM NFT 与 Solana SOL / SPL Token 归集，以及子域名扫描和网站路径扫描。

## 本地开发

```bash
npm install
npm run dev
```

质量检查：

```bash
npm test
npm run build
```

## 新增归集路由

| 功能 | 路由 | 输入格式 |
| --- | --- | --- |
| ERC20 代币归集 | `/evm/collect/` | 资产每行一个合约地址；密钥每行 `0x私钥` 或 `标签,0x私钥` |
| EVM NFT 归集 | `/evm/nft-collect/` | 支持 `1,3,8-12` 批量 ID、TXT / CSV，以及纯 RPC 的 Enumerable/Token ID 直接探测，也可直接编辑 `合约地址,Token ID` |
| SOL / SPL Token 归集 | `/sol/collect/` | 密钥每行 Base58、JSON 数组或 `标签,密钥`；Token 清单留空归集 SOL，填写 Mint 后归集所列 SPL Token |

三类归集都使用“解析输入 → 可选只读余额查询 → 明确确认 → 执行时即时规划 → 本地签名 → 逐项提交与确认”的流程。失败不会中断整批任务，提交后确认异常会保留交易哈希，并提示先核对链上状态，避免盲目重发。

所有工具页采用单栏工作台：全宽钱包或收款清单在上，配置区在下，摘要与执行按钮集中在底部。桌面配置字段可成对排列，手机自动堆叠。有效地址、合计金额、预计手续费与执行控制直接可见，完整日志可折叠；错误与重复项仅非零时出现，点击可以定位清单问题。静态说明通过问号展开，支持悬浮、点击、键盘与触屏；动态状态保持简短并可查看详情。

分发和部署不再需要手动运行预检：点击“开始分发”或“开始部署”后自动进行只读检查，通过后直接显示确认弹窗。检查失败不请求签名，取消弹窗回到编辑状态；再次开始会重新检查，确认执行时仍保留即时余额、费用、网络与模拟校验。

SOL / EVM 分发支持固定、随机和逐行金额。收款钱包和来源钱包共用“拖入文件或点击导入 → 弹窗粘贴或选文件 → 识别预览 → 钱包列表”的操作方式。收款文件支持 TXT / CSV / TSV / JSON / XLSX，自动识别不同列顺序、额外备注列和钱包对象，XLSX 多工作表可选择本次导入的表，金额保持文件原始精度；同地址同金额自动合并，同地址不同金额需修正。预览后选择追加或替换；可撤销一次导入，恢复清单、金额规则和随机金额。不同金额的文件只允许替换固定/随机清单，逐行金额清单之间可追加。SOL 部分失败会按收款地址关联交易批次，区分已确认、链上失败、未提交和待核对；可按原金额导出确定未转出的项目，并用逐行金额模式重新导入。进度以链上确认数为准。EVM 授权已确认但用户取消后续分发时，可重新检查余额和授权后继续；未知提交仍需先核对。

六个交易入口自动保存最近十轮公开任务记录，包含网络、目标地址、资产、数量和交易哈希。刷新后可只读查询交易回执或人工确认已核对；未知提交记录会阻止新的写入，多个标签页同步这一状态。记录不保存私钥、签名对象或 RPC 凭据。SOL 本地签名在广播前记下交易签名；EVM 未返回哈希的提交中断同样保守标记待核对。浏览器存储不可用时明确显示仅本页可查看，任务执行期间离开页面会提示。归集密钥支持本地 TXT / CSV / TSV / JSON / XLSX 导入，自动识别私钥列和常见钱包导出对象，并核对文件中声明的地址；导入前展示公开地址及问题行，需明确勾选才可仅导入有效项。XLSX 多工作表可明确选择当前表，公式单元格需先转为值。文件读取后立即清空选择控件；钱包列表支持地址/备注搜索和状态筛选。

## 一键归集

三个归集入口均可切换「手动归集 / 一键归集」，保留当前全部来源钱包、选中项以及网络、RPC 和目标地址。两种模式分别保留本页的资产清单、数量规则、执行节奏、Gas 和费用保护草稿；这些草稿不包含密钥或旧执行计划。密钥只通过临时内存引用交接，导入组件挂载后立即消费，页面关闭或卸载时清理。扫描只读，不签名；扫描期间展示逐钱包进度和部分只读结果，完成后可逐资产勾选或按合约排除，再核对网络、接收地址、实际数量规则和逐资产合计后确认执行。未选资产的钱包会保留原生币。

一键归集按全局阶段顺序执行：所有钱包 Token 完成后处理 NFT，最后按可选开关归集原生币。原生币默认关闭；扫描不完整、资产失败或跳过、仍有余额、复查失败、交易状态不确定的钱包保留原生币。每个钱包内逐笔执行，最多同时处理三个钱包。暂停和停止只影响后续操作，已提交交易继续确认；状态不确定的交易不自动重发，重新扫描或切换模式前需确认已核对链上结果。执行记录包含阶段、金额和交易哈希，可查看日志、导出 CSV，并保留最近十轮公开记录。

EVM 使用 Blockscout V2 发现 ERC-20、ERC-721 与 ERC-1155 候选资产，再通过当前 RPC 核对实时余额和所有权。Ethereum、Optimism、Gnosis、Base、Arbitrum、Sepolia 和 Base Sepolia 有默认资产索引；其他链可以填写对应的 Blockscout V2 节点。自定义索引的网络无法自动核验，因此只归集 RPC 已验证的资产，保留原生币。分页、请求或资产上限、限流、格式错误都视为扫描不完整。索引仅收到公开钱包地址，所有签名和发送使用当前选定链的 RPC。

Solana 一键扫描全部经典 SPL 和 Token-2022 账户，不需要填写 Mint 清单；同 Mint 的多个账户在概览中精确合并，但执行时逐个处理。零精度且数量为一的资产显示为 NFT；不支持压缩 NFT、Core 与需要专用流程的可编程 NFT。冻结或未知扩展资产保留并阻止该钱包的原生 SOL 归集。转移资产不会自动关闭来源 Token Account 或回收租金。

钱包资产概览最多直接显示两种 Token 的符号和简短数量，更多时显示「共 N 种 Token」，NFT 单独计数；问号内可查看精确数量及合约 / Mint。缺失符号使用缩短地址，相同符号但不同合约分别计数；未知、未扫描和扫描不完整不会显示为零资产。所有余额和汇总使用 bigint，避免大数或微小余额丢失精度。

Solana 手动归集采用与 EVM 代币归集一致的可选 Token 清单：留空查询并归集 SOL，填写 Mint 后只查询并归集所列经典 SPL Token / Token-2022。余额查询不是执行前置条件；每个钱包行始终先显示原生 SOL（包括 0 或读取失败），随后才显示清单内 Token。执行时会重新读取清单内持仓，并逐一保留和校验底层 Token Account，避免同一 mint 的多个账户被遗漏。基础 Token-2022 与 TransferFee 扩展可以进入受支持路径；冻结账户、NonTransferable、已暂停的 Pausable、TransferHook、ConfidentialTransfer、需要 MemoTransfer、动态显示余额的 InterestBearing / ScaledUiAmount，以及任何客户端无法识别、尚未审计或会改变转账账户要求的扩展都会 fail-closed，不会盲目签名或提交。任一 Token Program 的持仓查询不完整时不会生成 SPL 执行计划。

SPL Token 归集会验证目标 Associated Token Account（ATA）的 owner、mint 与 Token Program。目标 ATA 不存在时，预检会把创建 ATA 所需的租金和交易网络费计入来源钱包需要持有的 SOL；原生 SOL 不足时阻断该项。手动归集只转移用户明确填写在 Token 清单中的余额，不会自动关闭来源 Token Account，也不会自动回收其租金。

NFT Token ID 识别只使用当前 RPC，且不读取历史事件：ERC721Enumerable 调用 `balanceOf` / `tokenOfOwnerByIndex`；普通 ERC721 优先读取 `totalSupply` 与常见铸造计数器推算 Token ID 范围，再在固定快照并发调用 `ownerOf`，并用来源钱包的 `balanceOf` 判断是否找全。无法推算范围时可填写 Token ID 起止值。ERC1155 标准没有全量 Token ID 枚举接口，需手工或通过 TXT/CSV 提供已知 ID，执行前再调用 `balanceOf` 复核余额。

六个交易入口只在预检、导入、签名、提交、确认或扫描进行中锁定相关输入。终态可直接编辑、再次识别，或用“开始新一轮归集”在不改动任何设置的情况下继续；这三种动作都会把上一轮公开结果归档，归集记录最多保留最近 10 轮并可分轮导出 CSV。NFT 归档只移出确认成功的 Token ID，失败与未执行项留在清单里供下一轮使用。不确定交易仍需确认已核对链上状态后，才允许提交新的写入任务。NFT 失败行支持单项重试和“重试全部失败项”，已提交但状态不确定的交易不会进入重试集合。NFT 归集并发数由用户在 1–20 范围内设置；高于来源钱包数时只会执行现有钱包任务。

## 扩展新工具

工具入口统一登记在 `src/config/tools.ts`。新增功能时：

1. 在注册表增加工具元数据、分类和链支持；
2. 新增页面、entry 与对应 HTML 路由；
3. 在 `vite.config.ts` 登记入口；
4. 把解析、规划、执行逻辑放到 `src/lib` 并编写单元测试；
5. 对涉及密钥的页面调用独立的 `renderSensitivePage(page)`，确保敏感 bundle 不包含分析 SDK。

## 网络扫描工具

| 功能 | 路由 | 主要输出 |
| --- | --- | --- |
| 子域名扫描 | `/network/subdomains/` | 多源发现、发现来源、实时 DNS / CNAME、当前未解析或查询错误、疑似泛解析、CSV |
| 网站路径扫描 | `/network/paths/` | 自动路径发现、发现来源、HTTP 状态码分类、页面标题、响应声明长度、跳转地址、疑似软 404、暴露面探测、CSV |

两个工具都支持粘贴完整网址或包含网址的文本，粘贴时立即提取第一个匹配网址；手动输入会在离开输入框或开始扫描时提取。子域名扫描提取主机名；路径扫描保留入口路径，去掉查询参数和片段。手动输入过程中保留原文，无效或未完成的输入不会自动改写。

子域名扫描页面只需输入主域名，无需提供字典或填写外部结果。DNS 验证参数统一配置在 `src/config/subdomain-scan.ts`，默认并发 4、单项超时 5,000 毫秒，不在页面填写。六个自动来源包括免费的 Subdomain Center 数据库、CertSpotter / CertKit 证书记录、HackerTarget 被动 DNS、Pentest-Tools Light 子域名扫描和常用名称 DNS 补充。常用名称查询固定 32 个名称，补充尚未被公开索引收录的子站；先通过两个随机名称检查泛解析，只保留已解析且不是通配响应的结果，不把未解析的猜测计入发现，这一步只查询 DNS。各来源陆续返回时，新域名立即去重并加入当前 DNS 验证，已完成结果随即展示，无需等待全部来源结束。后到的来源补充同一域名的发现来源，不重复验证；DNS 返回的同域 CNAME 继续加入验证，保留 `cname` 线索标记，不作为独立发现来源查询或展示卡片。历史索引中已失效的域名显示为「当前未解析」。页面首次打开及每轮扫描默认展示「当前已解析」结果，不包含「疑似通配解析」；仍可切换到全部、疑似通配、当前未解析和验证错误，CSV 导出本轮全部已验证结果。最多验证 5,000 个子域名，来源失败、限流和达到上限均独立提示。

子域名自动发现已移除 crt.sh、Wayback、Anubis、网站公开链接和根域 DNS 元数据来源，不再为子域发现读取网页、脚本、站点地图或查询根域 NS / MX / TXT / SOA；普通 DNS 验证及同域 CNAME 扩展保留。使用 [Subdomain Center](https://github.com/ARPSyndicate/docs#subdomain-center) 的正式免费、无需 Key 接口，匿名查询最多返回 500 个随机样本，最终按每来源 5,000 个具体子域名限额保留。HackerTarget 免费接口每次最多 50 条且受每日配额限制，CertSpotter 查询未过期证书。公开来源的成功空响应显示「暂无收录」，不视为接口失效；达到来源上限、通配名称、失败和限流分别提示。外部数据库/证书结果缓存 10 分钟，错误缓存 30 秒（不缓存取消或本轮超时），最多 128 条；每轮 DNS 验证重新进行。多源发现和有限 DNS 补充无法保证获得全部子域名。Pentest-Tools 扫描最多 120 秒，其他来源请求最多 20 秒，并最多同时查询三个来源。

Pentest-Tools 参与每轮自动扫描，服务端通过其免费网页会话接口自动发起 Light 扫描、等待完成并提取当前域名内的子域名，结果与其他来源去重后进入实时 DNS 验证，来源标记和 CSV 保留 `pentesttools`。无需单独打开网页或填写 API Key；该流程受免费网页额度及接口兼容性限制，额度耗尽、接口变化或超时会独立显示，不影响其他来源。缓存命中或同域扫描正在进行时复用已有结果或任务，避免重复发起远端扫描。

CertKit 通过 [免费 CT 查询工具](https://www.certkit.io/tools/ct-logs/) 使用的 `POST https://ct.certkit.io/search` 接口参与自动查询。固定发送当前主域名、`limit: 100` 和默认排序，无需登录、API Key 或 Cookie；从证书的 `commonName` 和 `dnsNames` 提取具体名称，包含历史过期证书，并只保留当前域名内的子域名。免费查询最多返回 100 张证书；`totalCount` 大于已返回数量时标记「部分结果」，不尝试付费入口或扩大免费限额。结果使用 `certkit` 来源标记、20 秒查询时限和现有缓存，去重后进入实时 DNS 验证；通配证书仅提示，限流和失败独立显示。

SSLMate CT Search 与 Cert Spotter 使用同一个证书查询接口。可在本地 `.env.local` 配置 `SSLMATE_API_KEY=你的BearerToken`，重启开发或预览服务后，证书来源会显示「已通过 SSLMate 认证查询」。Vercel 使用同名的服务端环境变量。Key 仅发往固定的 SSLMate HTTPS 查询接口，不发送给扫描目标或其他来源，也不进入前端；不要使用 `VITE_` 前缀。`.env.local` 已被 Git 忽略，应限制为仅当前用户可读写。未配置时继续匿名查询；无效、停用、权限不足和配额限制会分别提示，不自动重试或降级绕过认证。免费 Small 套餐当前允许每小时 10 次全域查询，实际限制以 [SSLMate 官方说明](https://sslmate.com/ct_search_api/) 为准；认证无法从通配证书恢复未公开的具体名称。

网站路径扫描只需输入网站地址，自动汇总同源页面链接、脚本中的路径线索、robots.txt、Sitemap 与 Wayback 历史记录，不需要字典。HTTP 入口明确跳转至同主机 HTTPS 时，自动改用该公开入口继续扫描。脚本分析支持可静态确认的路由前缀、导航函数和有限参数清单，恢复由配置生成的具体页面；不执行脚本，不猜测任意动态参数。CSS、JavaScript、图片、字体等普通静态文件不进入结果、响应验证或 CSV；脚本和 Sitemap 仍可作为线索读取，固定暴露探测项另行保留。扫描范围为整个当前网站，包含入口目录之外的同源路径；去掉查询参数和片段后去重，并保留发现来源。发现与响应验证同时进行，新路径发现后即可验证并展示已完成结果，后到的来源更新已有结果。后续线索若确认某项是普通静态资源，会将它从路径结果移除；若确认是前端路由，则更新路由标记并撤销不适用的暴露判定。

路径发现最多 90 秒，每轮最多保留 2,000 个站点路径，最多读取 100 个页面、40 个脚本、20 个 Sitemap；页面抓取深度最多 3 层，脚本依赖由独立文档上限约束。达到 90 秒时限只结束未完成的发现请求，已保留路径继续响应验证；所有发现来源结束后，剩余验证完成才结束扫描。发现进度与验证进度分别显示，验证总数随新路径加入而增长。来源失败和达到限制时明确标记数据不完整，入口 404 或访问受限会直接说明原因。响应验证并发 1–8，站点请求使用所设的 1–10 秒超时，Wayback 最长 20 秒。未公开引用或只能在运行时确定的路径仍可能遗漏。已解析子域名可通过「扫描路径」预填其网址继续扫描。两个工具都可以停止，同时取消发现与验证请求，保留已完成结果；扫描过程中即可筛选、搜索和导出 CSV。每页显示 100 条，搜索与导出覆盖本轮全部已完成结果。

网站在发现阶段被确认可读后，路径扫描还会对固定清单中的 44 个常见暴露路径各发一次 GET（`.env`、`.git/HEAD`、`.git/config`、`.aws/credentials`、`backup.sql`、`database.sql`、`phpinfo.php`、`swagger.json`、`openapi.json`、`actuator/env`、`server-status`、`adminer.php` 等）。清单固定在 `src/lib/exposure-path.ts`，不随目标或输入变化，不构成字典爆破。固定清单与站点发现的路径合并后仅验证一次，并保留发现来源。只有返回 2xx、随机不存在路径的对照请求成功并提供可比较指纹、且不是脚本声明的前端路由时才可能标记为「高置信暴露」或「疑似暴露」；对照请求失败或响应相同时不给出暴露判定。`.well-known/security.txt`、`robots.txt`、`sitemap.xml` 等本就公开的声明不会成为暴露发现项。未命中的纯探测项不进入普通结果统计，站点自身发布的路径仍保留。暴露面单独成组并可按置信度筛选，判定结果与单项请求耗时随 CSV 导出，备份压缩包等固定探测项也会保留；命中后应先人工确认内容，再决定下线文件与轮换凭据。

子域名验证通过服务端 DNS 查询 A / AAAA 和 CNAME；随机不存在名称用于检测泛解析。路径扫描通过服务端 GET 读取最多 64 KiB 的响应样本，并与随机不存在路径比较；相同响应标记为疑似软 404。明确由脚本声明且返回 2xx 的前端路由单独标记为「前端路由」，说明统一应用入口尚未执行内容验证；原始响应相似标记仍保留在 CSV。路由声明不能覆盖 404、410 或请求错误。随机探测不计入用户结果的进度和导出。泛解析与软 404 标记是辅助判断，受动态响应和 DNS 轮询影响。403 / 401 表示受限响应，404 / 410 表示未找到；超时与请求错误单独显示。单次 HTTP 请求不自动跟随跳转；同源跳转作为发现线索单独读取和验证，入口仅允许有实际跳转证据的同主机 HTTP → HTTPS 升级，其他跨源跳转不跟随。

扫描 API 为 `POST /api/network-scan`，开发和 `npm run preview` 使用 Vite 中间件；Vercel 部署使用 `api/network-scan.ts` 的 Node 函数，设置最长 150 秒以覆盖 Pentest-Tools 来源查询的 120 秒超时。纯静态托管需要额外运行该 API，否则页面会明确报告扫描服务不可用。服务端 HTTP 连接仅允许公网默认端口，拒绝私网、回环、保留地址及混合公网/私网解析；连接固定使用已检查的 DNS 地址，HTTPS 保留域名证书校验。GET 响应头到达前遇到连接故障时，最多在三个已检查 IP 间切换，所有尝试共享原始超时；POST 不自动重试，以免重复创建远端扫描。HTTP 错误、证书错误和取消不会触发重试。纯 DNS 验证可以展示包含私网地址的解析记录并附注，但不会向这些地址发送 HTTP 请求。请求体、响应样本、超时、活动请求数与请求频率均设有上限，频率限制为进程内保护。请用于自己拥有或获授权的目标。

## 安全边界

- 私钥在浏览器当前页面中解析和签名，不写入 localStorage、sessionStorage、IndexedDB，也不发送到本站服务器。
- 敏感归集页面关闭站点分析组件；错误信息会隐藏私钥和 RPC 地址。
- EVM 交易严格执行 `simulateContract → writeContract → waitForTransactionReceipt`；SOL 逐钱包实时读取余额和手续费后再签名。
- Solana SPL 归集同时支持经典 Token Program 与受限的 Token-2022 安全子集；未知或会改变转账语义的扩展一律 fail-closed。
- 创建目标 ATA 所需租金和网络费必须由预检计入原生 SOL 需求；工具不会自动关闭来源 Token Account 或回收账户租金。
- 归集结果 CSV 保留原有列，并包含网络、来源/目标地址、完整合约、资产标准和 Token ID；历史记录刷新后仍可导出这些公开字段及交易链接。旧记录缺失的合约或 ID 保持空白，不从简写名称猜测；导出不包含密钥。
- 暴露面探测只请求 `src/lib/exposure-path.ts` 中的固定清单，每个路径最多一次 GET，响应样本上限 64 KiB，不提交表单、不登录、不执行脚本；命中项按线索呈现，需人工确认后再处理。
- 浏览器任务对来源钱包、资产数量和余额读取组合数设置硬上限；超限会要求拆批，不会直接放大 RPC 或签名队列。
- 当前版本不是经过安全审计的托管产品。主网使用前请先在测试网或小额钱包验证，并优先使用专门的操作钱包。
